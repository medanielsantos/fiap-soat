# Architecture Decision Records (ADRs)

ADRs registram decisões técnicas importantes, seu contexto e seus efeitos. Um ADR aceito passa a orientar implementação e documentação; decisões propostas aguardam revisão.

## Ciclo de vida

Cada ADR registra contexto, decisão, alternativas e consequências. Estado: **Proposto**, **Aceito** ou **Substituído**. Ao revisar uma decisão aceita, atualizar o ADR e registrar o motivo; não apagar o histórico da escolha anterior.
